# 测试脚本文件夹

本目录用于统一存放自动生成的测试脚本。

## 组织规则

1. 所有自动生成的测试脚本统一放在本目录下。
2. 以生成时间建立子目录，命名格式：`YYYY-MM-DD_HH-MM-SS`。
3. 同一批次生成的多个脚本文件放入同一个时间子目录。
4. 原始输入文件（如 .xmind、源 .xlsx）不要放入本目录。
5. 临时生成脚本、中间调试文件等应放入 `临时文件夹/`，由作者自行决定是否删除。

## 示例

```
测试脚本文件夹/
├── README.md
├── 2026-07-15_16-10-00/
│   ├── multihost_test_tc001.py
│   └── multihost_test_tc002.py
└── 2026-07-14_15-35-00/
    └── multi_pf_test_tc001.py
```
