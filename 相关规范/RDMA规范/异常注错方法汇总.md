# 异常注错方法汇总

> 来源：xmind文件夹/天蝎 RDMA异常处理AEQE.xlsx、天蝎 RDMA异常处理MQ.xlsx、原型验证-异常专项.xls、异常构造.docx

## 一、AEQE 事件注错方法（天蝎 RDMA异常处理AEQE.xlsx）

### context_access_error（type=0x30）

- 子类型/细节：0x1：TX_WQE load QPC error
0x2：RX_ENG load QPC error
0x3：TMO load QPC error
0x4：CC load QPC error
0x5：DCT load QPC error
0x6：CQEQ load QPC error
- 注错方法：启用qp的个数超过256，然后打流（所有qp都要有流），打流过程中往0x844a205c写入0xB对qpc cache dma读接口注错

- 子类型/细节：0x7:   RX_ENG load SRQC error
- 注错方法：往0x84490000写0x1配置srqc cache为bypass模式，启用srq打流（1个srq即可），打流过程中往0x844a205c写入0x1B对srqc cache dma读接口注错

- 子类型/细节：0x10：CQEQ load CQC error
0x11：CQEQ load CEQC error
- 注错方法：往0x844c8000写0x1配置cqc/eqc cache为bypass模式，启用cq的个数超过64，然后打流（所有cq都要有流），打流过程中往0x844a205c写入0x6B对cqc/eqc cache dma读接口注错

- 子类型/细节：0x12：CC load CC_Context error
- 注错方法：往0x844b4000写0x1配置cc cache为bypass模式，启用cc打流（1个qp即可），打流过程中往0x844a205c写入0x63对cc cache dma读接口注错

- 子类型/细节：0x20：回写QPC到ICM空间时出现VA2PA错误
- 注错方法：启用qp的个数超过256，然后打流（所有qp都要有流），打流过程中往0x844C4254写0x1000

- 子类型/细节：0x21：回写CQC到ICM空间时出现VA2PA错误
0x23：回写EQC到ICM空间时出现VA2PA错误
- 注错方法：往0x844c8000写0x1配置cqc/eqc cache为bypass模式，启用cq的个数超过64，然后打流（所有cq都要有流），打流过程中往0x844C4254写0x800

- 子类型/细节：0x22：回写SRQC到ICM空间时出现VA2PA错误
- 注错方法：往0x84490000写0x1配置srqc cache为bypass模式，启用srq打流（1个srq即可），打流过程中往0x844C4254写0x400

- 子类型/细节：0x24：回写MRC到ICM空间时出现VA2PA错误
- 注错方法：往0x844C51A0写0x11配置L1 mrc cache深度为64，往0x844ca000写0x1配置L2 mrc cache为bypass模式，往0x844C4254写0x200，创建超过64个MR，

- 子类型/细节：0x25：回写CCC到ICM空间时出现VA2PA错误
- 注错方法：往0x844b4000写0x1配置cc cache为bypass模式，启用cc打流（1个qp即可），打流过程中往0x844C4254写0x100

### ceq_error（type=0x31）

- 子类型/细节：0x0：Reserved
0x1：CEQ溢出
0x2：销毁CEQ前未将绑定的QP/CQ排空
0x3：读CEQ DBR发生DMA error
0x4：读CEQ PBL发生DMA error或PBL非4K对齐
0x5：读CEQ FPT发生DMA error或FPT非4K对齐
- 注错方法：0x1：当前方案默认不上报该错误；
0x2：带流销毁ceq；
0x3：中断模式，CEQ深度设置为4，0x844d0024写入0x9B，持续打流，不按EQ门铃，
0x4~0x5：中断模式，CEQ buffer页大小设置为4K，0x844d0024写入0x9B，持续打流，

### function_resource access_error（type=0x32）

- 子类型/细节：0x0：Reserved
0x1：CQ片外门铃FIFO读取PBL发生DMA error或PBL非4K对齐
0x2：CQ片外门铃FIFO读取门铃entry时发生DMA error
0x3：TMO片外entry FIFO读取PBL发生错误
0x4：TMO片外entry FIFO读取主机发生DMA error
- 注错方法：0x1：往0x844c0140写0x8，0x844C4254写0x2，一直按CQ门铃（可按重复门铃）；
0x2：往0x844c0140写0x8，0x844a205c写入0x73对cqdb cache dma读接口注错，一直按CQ门铃（可按重复门铃）；
0x3：0x844C4254写0x1，启用32 RC qp持续打流
0x4：往0x844b2000写0x1配置tmo cache为bypass模式，往0x844a205c写入0x33对tmo cache dma读接口注错，启用32RC qp持续打流

### uar_back_pressure_timeout_error（type=0x33）

- 子类型/细节：0x0：Reserved
0x1：CQEQ反压门铃页面超时
0x2：主机侧CQ门铃FIFO溢出
- 注错方法：0x2：往0x844c0140写0x8，一直按CQ门铃（可按重复门铃）；

### db_proc_error（type=0x34）

- 子类型/细节：0x0：Reserved
0x1：uar门铃非8B对齐
0x2：LLWQE长度非法
0x3：UAR门铃反压门铃页面超时
0x4：门铃挂链检查失败，Qset未启用
0x5：门铃挂链检查失败，Qset绑定fid不匹配
0x6：门铃挂链，Qset PA地址无效，丢弃门铃
0x7：门铃挂链，读取bitmap返回error，丢弃门铃
0x8：门铃摘链，Qset PA地址无效，丢弃门铃
0x9：门铃摘链，读取Qset DB Cache返回error，丢弃门铃
- 注错方法：0x2：LL_WQE长度配置为0；
0x4：按门铃时填入未启用的Qset ID
